# 1 · Datos de conexión

Broker (MQTT sobre WebSocket)
—
Espacio de tópicos
taller/<grupo>/<dispositivo>/<métrica>
Usuario
el nombre de tu grupo (p. ej. grupo1)
Contraseña
el token del taller (te lo da el docente)

Cambia el token y el grupo y los scripts de abajo se actualizan solos. Cada grupo solo puede publicar bajo su propio nombre.

# 2 · Opción Python pip install paho-mqtt


    
Guárdalo como sensor.py y ejecútalo: python sensor.py

  


  

    
# 2 · Opción Node npm init -y && npm install mqtt

    

    
Guárdalo como sensor.js y ejecútalo: node sensor.js
